# Собственный VPN — памятка управления

## Назначение

Этот документ описывает текущую личную VPN-инфраструктуру и повторяемые действия по её обслуживанию. Он намеренно **не содержит** IP-адрес сервера, пароли, SSH-ключи, URL панели с секретным путём, QR-коды и ссылки подписок. Такие данные хранятся только в панели провайдера, менеджере паролей и выданных пользователям ссылках.

## Текущая схема

- Сервер: Ubuntu VDS у Koara.
- Панель управления: 3x-ui; для внешнего доступа используется HTTPS-прокси Caddy на отдельном порту.
- Клиентский протокол: VLESS поверх TCP + TLS на порту 443.
- Сертификат: настоящий сертификат домена, которым управляет Caddy.
- Мобильный клиент: Happ для iOS.
- Windows-клиент: FLClashX.
- WireGuard/wg-easy удалён. Старый Outline остановлен и не должен запускаться одновременно с Xray, поскольку конфликтует за порт 443.

Для совместимости с Happ новые профили используют TLS **без** Reality и Vision (`flow` не задан). Это подтверждённый рабочий вариант.

## Доступ к управлению

1. Открой сохранённый ярлык «Мой VPN — управление» на рабочем столе Windows.
2. Войди в 3x-ui, используя пароль из менеджера паролей или панели Koara.
3. Рабочие разделы:
   - «Входящие» — один входящий VLESS/TLS на порту 443;
   - «Клиенты» — создание, отключение и просмотр пользователей;
   - «Настройки панели» — только для изменения самой панели, не клиентских профилей.

Не публикуй адрес панели, учётные данные, QR-коды или ссылки подписок в открытых чатах.

## Как создать нового клиента

1. Открой «Клиенты» → «Создать клиента».
2. Укажи понятную метку, например `family-iphone-01` или `family-windows-01`.
3. Оставь трафик `0` (безлимитно), срок действия пустым, статус «Включить» — активным.
4. Привяжи клиента к VLESS/TLS входящему на порту 443.
5. Для iPhone включай лимит HWID `1`: первая подписка привязывает ссылку к одному устройству.
6. Для Windows лучше создать отдельного клиента. Лимит IP `1` ограничивает одновременное использование, но не является жёсткой привязкой к конкретному устройству.
7. Не задавай `flow=xtls-rprx-vision` для профилей Happ/FLClashX, если нет отдельной проверки совместимости.
8. Нажми «Создать» и выдай человеку только его ссылку или QR-код.

## Выдача доступа

### iPhone / Happ

1. Устанавливать Happ следует только с [официального сайта Happ](https://www.happ.su/main/ru), выбрав российский App Store при необходимости.
2. Для Happ выдать обычную ссылку подписки или QR-код, созданный из неё.
3. В Happ: `+` / «QR-код» → сканировать → выбрать появившийся сервер → включить большую кнопку питания.
4. Если у клиента лимит HWID = 1, нельзя проверять его ссылку через `curl` с произвольным заголовком `X-HWID`: такая проверка может занять единственную привязку устройства.

### Windows / FLClashX

1. В 3x-ui экспортировать **Clash-подписку** выбранного клиента (адрес вида `/clash/<subId>`), а не прямую `vless://`-ссылку.
2. В FLClashX: `+` → `URL` → вставить Clash-подписку → «Подтвердить».
3. Выбрать профиль и включить `System Proxy` (или режим TUN, если он нужен для всего трафика).

## Ограничение «одна ссылка — одно устройство»

Для iPhone-профилей используется `HWID limit = 1`.

- Первый телефон, который загружает подписку, становится привязанным.
- Второй телефон с этой же ссылкой должен быть отклонён.
- При смене телефона удалить старую HWID-привязку в карточке клиента панели, затем обновить подписку на новом телефоне.
- Ошибка Happ `404 Not Found` сразу после выдачи ссылки обычно означает, что HWID уже привязан к другому устройству или тестовому запросу. Сначала сбросить HWID-привязку, затем в Happ нажать обновление `↻`.

## Быстрая диагностика

### Сервер доступен, но VPN не подключается

1. В панели проверить, что входящий VLESS/TLS на 443 включён.
2. Проверить, что сервис 3x-ui работает: `systemctl is-active x-ui`.
3. Проверить прослушивание порта: `ss -ltnp | grep ':443'`.
4. Убедиться, что UFW разрешает TCP 443, 8443 и SSH 22.
5. В 3x-ui посмотреть трафик и `last online` клиента. Нулевой трафик означает, что приложение ещё не установило VPN-соединение.

### Happ показывает 404 при обновлении подписки

1. Проверить лимит HWID и существующую HWID-привязку клиента.
2. Сбросить привязку только если человек действительно меняет устройство или прежняя привязка была тестовой.
3. В Happ нажать `↻` у сохранённой подписки. Не создавай новую ссылку без необходимости.

### FLClashX не импортирует профиль

Причина почти всегда в том, что вставлена прямая `vless://`-ссылка. Для пункта `URL` в FLClashX нужна именно Clash-подписка, экспортированная из 3x-ui.

## Проверка после изменений

После изменения входящего, сертификата или сервисов:

1. Убедиться, что `x-ui` активен и порт 443 открыт.
2. Проверить получение подписки конкретным приложением, не занимая HWID тестовым запросом.
3. Подключить один тестовый iPhone и открыть обычный сайт.
4. Проверить, что внешний IP в браузере меняется на IP сервера.
5. При необходимости проверить отдельный Windows-профиль в FLClashX.

## Известные ограничения и правила безопасности

- iOS не даёт приложению VPN универсально включаться только для отдельных приложений; это ограничение самой платформы.
- Доступ к панели даёт полный контроль над всеми пользователями. Храни его только у владельца.
- При выдаче родственнику создавай отдельного клиента; не передавай личную или административную ссылку.
- Не запускай одновременно старый Outline и Xray на порту 443.
- Не меняй конфигурацию Xray или базу 3x-ui вручную, если изменение можно сделать в панели: это уменьшает риск сломать подписки и HWID-привязки.
