# 🎓 Barber Academy Bot - Инструкция по настройке

## 📋 Быстрый старт

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта:
   ```
   BOT_TOKEN=ваш_токен_бота
   ```

3. **Запустите бота:**
   ```bash
   npm run bot
   ```

4. **База данных:**
   БД SQLite создастся автоматически в папке `data/barber.db` при первом запуске.

---

## 👤 Настройка администратора

Чтобы назначить пользователя администратором, выполните в консоли Node.js:

```javascript
import db from './bot/database.js'
import { UserRole } from './bot/dbService.js'

// Замените TELEGRAM_ID на ваш Telegram ID (можно узнать у @userinfobot)
const telegramId = YOUR_TELEGRAM_ID

// Создаём или обновляем пользователя
const user = db.prepare('SELECT * FROM users WHERE telegram_id = ?').get(telegramId)
if (user) {
  db.prepare('UPDATE users SET role = ? WHERE telegram_id = ?').run(UserRole.ADMIN, telegramId)
  console.log('Пользователь назначен администратором')
} else {
  console.log('Пользователь не найден. Сначала зарегистрируйтесь через /start')
}
```

Или используйте SQL напрямую:
```sql
UPDATE users SET role = 'admin' WHERE telegram_id = YOUR_TELEGRAM_ID;
```

## 👨‍🏫 Настройка преподавателя

Аналогично администратору, но роль `'teacher'`:

```javascript
db.prepare('UPDATE users SET role = ? WHERE telegram_id = ?').run(UserRole.TEACHER, telegramId)
```

Также нужно создать запись в таблице `teachers`:

```javascript
import { createTeacher } from './bot/dbService.js'
const user = db.prepare('SELECT * FROM users WHERE telegram_id = ?').get(telegramId)
if (user) {
  createTeacher(user.id, 'Имя Преподавателя')
}
```

## 🔄 Сценарии работы

### Регистрация ученика
1. Ученик отправляет `/start`
2. Вводит ФИО, телефон, количество занятий
3. Заявка сохраняется в БД со статусом `moderation`
4. Администратор получает уведомление

### Модерация
1. Администратор отправляет `/admin`
2. Выбирает "Список на модерации"
3. Нажимает "✅ Одобрить" или "❌ Отклонить"
4. Ученик получает уведомление

### Сдача ДЗ
1. Активный ученик отправляет `/start` → "📤 Сдать домашнее задание"
2. Выбирает номер урока или "Дополнительное задание"
3. Отправляет фото/видео/текст
4. Преподаватели и администратор получают уведомления

### Проверка ДЗ
1. Преподаватель отправляет `/teacher`
2. Видит список учеников с количеством непроверенных заданий
3. Выбирает ученика → видит список заданий
4. Нажимает "✅ Принять" (вводит оценку 1-5 и комментарий) или "❌ Отклонить"
5. Ученик получает уведомление с результатом

## 📊 Структура базы данных

- `users` - пользователи (ученики, преподаватели, админы)
- `students` - данные учеников
- `teachers` - данные преподавателей
- `student_teachers` - связь ученик ↔ преподаватели
- `homeworks` - домашние задания
- `homework_reviews` - проверки заданий

---

## 🛠️ Полезные команды

- `/start` - регистрация или главное меню (для учеников)
- `/admin` - админ-панель
- `/teacher` - панель преподавателя
- `/reset` - сброс текущего диалога

---

## ⚠️ Важно

- БД файл `data/barber.db` не коммитится в Git (добавлен в .gitignore)
- Для продакшена рекомендуется использовать PostgreSQL
- Токен бота храните в `.env` и не коммитьте его
