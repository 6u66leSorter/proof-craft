# MADCAP Barber Academy — Веб-приложение

## Описание
Мобильное веб-приложение для барберской академии с 4 ролями: **Ученик**, **Преподаватель**, **Администратор**, **Гость**.

## Структура файлов
```
barber-academy.html   — основной HTML файл (разметка + JS логика)
styles.css            — все стили приложения (CSS)
README.md             — этот файл
```

## Технологии
- **Чистый HTML/CSS/JS** — без фреймворков и сборщиков
- **LocalStorage** — хранение данных (DB-обёртка в JS)
- **Telegram WebApp API** — поддержка запуска как Telegram Mini App
- **Google Fonts** — Playfair Display + Nunito Sans

## Роли и функционал

### Ученик
- Регистрация с фото, ФИО, телефон, станция метро
- Профиль со статистикой (занятия, средний балл)
- Загрузка ДЗ с **несколькими фотографиями**
- Исправление работ по замечаниям преподавателя
- Чат с преподавателем
- Уведомления

### Преподаватель
- Регистрация/вход
- Список своих учеников
- Проверка ДЗ с оценкой и замечаниями
- Чат с учениками
- Уведомления

### Администратор
- Вход по паролю (по умолчанию: `admin` / `admin`)
- Одобрение/отклонение заявок
- **Назначение преподавателей ученикам** через чекбоксы (галочки)
- Настройка учеников (статус, кол-во занятий, преподаватели)
- **Просмотр профиля преподавателя** с его учениками
- Уведомления

### Гость
- Просмотр портфолио учеников (без барберов)
- Видит станцию метро каждого ученика

## Дизайн-система
Все CSS-переменные в `:root` файла `styles.css`:
- `--gold: #C9A227` — основной золотой цвет
- `--bg: #080808` — фон
- `--bg2, --bg3` — вторичные фоны
- `--border` — границы (полупрозрачный золотой)
- `--font-display` — Playfair Display (заголовки)
- `--font-body` — Nunito Sans (текст, кнопки, бейджи)
- `--glow` — gold box-shadow для карточек
- `--card-bg` — gradient для карточек

## Как запустить
1. Просто откройте `barber-academy.html` в браузере
2. Или разместите оба файла на веб-сервере

## Особенности кода
- **DB** — обёртка над localStorage (`DB.get`, `DB.set`, `DB.del`, `DB.all`)
- **state** — глобальный объект состояния с навигационным стеком
- **go() / back()** — навигация по экранам
- **render()** — switch-case рендер текущего экрана
- **compressImg()** — сжатие фото перед сохранением в base64
- **seed data** — тестовые данные создаются при первом запуске

## Для продолжения разработки
- JS-логика находится внутри `<script>` тега в HTML файле
- При необходимости можно вынести JS в отдельный файл `app.js`
- Данные хранятся в localStorage — при очистке всё сбрасывается
- Логотип закодирован в base64 в переменной `ACADEMY_LOGO`
